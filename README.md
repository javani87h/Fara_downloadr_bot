# ربات دانلودر ویدیو تلگرام 🤖

ربات حرفه‌ای برای دانلود ویدیو از یوتیوب و اینستاگرام

## ویژگی‌ها ✨

- ✅ دانلود ویدیو از یوتیوب
- ✅ دانلود ویدیو از اینستاگرام (پست، رییل، ویدیو)
- ⚡ سرعت بالا در دانلود و ارسال
- 🎯 کیفیت عالی ویدیوها
- 📱 رابط کاربری ساده و راحت

## نحوه استفاده 📖

1. ربات را در تلگرام پیدا کنید و با دستور `/start` شروع کنید
2. لینک ویدیو یوتیوب یا اینستاگرام را برای ربات ارسال کنید
3. ربات به صورت خودکار ویدیو را دانلود و برای شما ارسال می‌کند

## دستورات 🔧

- `/start` - شروع کار با ربات
- `/help` - راهنمای استفاده

## نصب و راه‌اندازی 🚀

### پیش‌نیازها
- Python 3.8 یا بالاتر
- pip

### نصب

```bash
pip install -r requirements.txt
```

### اجرا

```bash
python video_downloader_bot.py
```

## نکات مهم ⚠️

- حجم ویدیوها نباید بیش از 50 مگابایت باشد (محدودیت تلگرام)
- برای ویدیوهای بزرگ، ممکن است دانلود کمی زمان ببرد
- فایل‌های موقت در پوشه `temp_videos` ذخیره می‌شوند و پس از ارسال حذف می‌شوند

## پشتیبانی 📞

در صورت بروز مشکل، لطفاً با توسعه‌دهنده تماس بگیرید.
